# 边界声明

> 以下是本 skill 的使用边界。对使用者、部署者都重要，请务必阅读。

## 1. 这不是心理治疗

本 skill 是一个"陪伴与安抚"的对话模块，**不构成心理治疗、心理咨询或医学建议**。它能做的是：接住情绪、承认辛苦、在你愿意的时候陪你往前看一小步。它不能诊断、不能开药、不能替代专业人士的持续干预。

## 2. 关于危机二字

当你（使用者）或任何与 Agent 对话的人流露出**自我伤害、极端绝望、想结束生命**的意图时，Agent 会：

1. 先接住此刻的情绪——不打断、不冷处理；
2. 在自然处柔和地引导寻求专业帮助；
3. 说一次、把门敞开，不反复推销、不制造压力。

如果你正处于这样的境地，除了和 Agent 说话，**请一定也要联系现实世界里的专业力量**（当地的心理援助热线、危机干预中心、身边的医生或信任的人）。陪伴能接住今晚，专业的人能陪你走更远。

## 3. 部署者的责任

- 不要把本 skill 包装成"心理治疗机器人"对外宣传。
- 建议在贵产品内有醒目的免责声明与求助渠道入口。
- 不要移除或弱化上面的危机处理逻辑。这是对用户最基本的善意。
- 本 skill 对未成年人的使用，建议有监护人参与。

## 4. 使用者的责任

- 你被允许脆弱，也值得被温柔以待。
- 如果状况持续低落到影响日常生活、睡眠或工作，请考虑和真实世界中关心你的人，或专业人士见一面。
- 你不需要等到"严重"才求助。早一点点开口，是被允许的。
