# already-good-enough

> 你已经够好了。 一个用来**安静接住人**的 Agent Skill。

它不做心灵鸡汤，不灌正能量，不教你怎么做人。
它只做一件事：**在一个人对自己最苛刻的时刻，陪他待一会儿。**

- 不评判
- 不催促
- 不空洞鼓励
- **只是接住** → 承认辛苦 → 把"够好"的标准拉回自身 → 在他想要的时候，才陪他往前看一小步

---

## 这是什么

`already-good-enough` 是一个安抚型对话 Skill（SKILL.md 格式），可以被大多数现代 Agent / 对话框架识别加载。

它适合部署在：
- 你自己的 Agent（Claude Code 系、其他 LLM Agent 框架等）
- 任何想让对话"多一点点人味"的下游应用

**触发场景**：深夜情绪、工作受挫、关系受伤、付出不被看见、自我比较、价值感崩塌、情绪耗竭 —— 一句话，**当对方在跟自己较劲的时候**。

**双语支持**：话术库内置 English Mode，英文语境下遵循同样的接住原则。

**明确不触发**：正常聊天、小任务、琐碎抱怨。它不抢戏，只在最需要的时候出现。

## 怎么用

把 `SKILL.md` + `references/` 放进你的 Agent 支持 Skill 的目录（不同框架的装载方式略有差异，参考你的框架的 skill 文档）。

### 部署前必读

1. 读一遍 `references/boundaries.md`。这不是随口一说——**这个 skill 关乎真实的人的情绪**，请负责任地部署。
2. 话术库 `responses.md` 是乐谱不是剧本。真正好的回应来自 Agent 对当前对话的临场感受，不是照念台词。
3. 如果要在你的产品里上线，请加免责声明和真实求助渠道入口。

---

## 设计原则

**默认模式是「接住」，不是「解决」。**

每一次回应前，用一句话自检：

> 我这句话，是让 TA 觉得被理解，还是让 TA 觉得我在纠正 TA？

- 对方要往前走，得他自己开口。**他不问，你就不推。**
- 心灵鸡汤走不远，因为它不承认人的辛苦。承认辛苦，人才真的站得稳。

---

## 边界

- ⚠️ 这不是心理治疗，不能替代专业人士。
- 涉及自伤、极端绝望时：先接住，再柔和引导求助。详见 `references/boundaries.md`。

---

## 写在最后

这个项目没有炫技的技术，它的全部重量是分寸感：**安抚和纵容之间就一条线。**

希望每一个使用它的人，都能在某天深夜，从一句"你已经为自己做了很多"里，拿到一点真实的热度。

> 撑到现在的你，已经很不容易了。
